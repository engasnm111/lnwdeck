# lnwdeck source audit - 2026-08-04

Scope: full repository audit at commit `f05f604` (branch `main`), verification of every claim
made in `CHANGELOG.md` 0.2.0 and `docs/releases/v0.2.0.md`, plus new findings, followed by the
remediation record for each item.

Method: source code is the only authority. Documentation claims were checked against the code
paths that would have to implement them. Every verdict below carries a `file:line` reference.
Verdicts: CONFIRMED (claim matches code), PARTIAL (claim true only under conditions the docs do
not state), FALSE (code contradicts the claim).

### 2.4 What was not executed

- The updater chain was verified through signature verification of the real
  signed installer against the shipped public key, and through manifest
  generation from the real artifacts. Installing an older build and letting it
  update itself was not run, because that installs and replaces application
  versions on this machine beyond the requested change. The unverified step is
  the NSIS installer invocation that `download_and_install` performs after
  verification succeeds.
- Only the `x86_64-pc-windows-msvc` bundle was built locally; ARM64 and x86 come
  from the release workflow, which fails when no signature is produced.
- Claude's published quota could not be exercised on this machine: no Claude Code
  credential is stored here, so the adapter fell back to local usage windows. The
  Codex path was exercised live and returned a real 90%-used weekly window, which
  is what the widget screenshot shows.
- No Git tag was created, nothing was pushed, and no GitHub release was
  published.
