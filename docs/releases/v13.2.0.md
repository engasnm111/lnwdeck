# lnwdeck v13.2.0

Release date: 2026-11-23

This release restores quota reporting for providers whose local credential or
log layout changed after v13.1.0, refreshes the dependency stack, and clears
the dependency-audit findings that made the scheduled Security workflow fail.

## Features

- **ZCode 3.14+ quota works again.** ZCode stopped writing `v2/config.json`;
  the adapter now decrypts the `v2/credentials.json` store in memory, accepts
  the per-account coding-plan keys ZCode writes there, prefers the account that
  owns the current login, and honors the active region's plan. Team plans send
  their organization/project scope; start plans keep the local billing log
  fallback.
- **`CREDIT_LIMIT` quota rows.** ZCode 3.17.1 renamed the 5-hour and weekly
  token rows, so both `TOKENS_LIMIT` and `CREDIT_LIMIT` now anchor the named
  windows.
- **Qoder Desktop 0.4.x quota.** The account usage summary moved to `main.log`
  under the bundle-id profile; the adapter scans both profile layouts and reads
  the `qoderUsage` snapshot, including add-on credits.
- **Qoder CN endpoint.** The CN adapter uses the current `qoder.cn` account
  endpoint.

## Security

- Bundled SQLite is now 3.54.1 through rusqlite 0.43, which fixes
  CVE-2026-119375 (uninitialized page-cache memory when a crafted `-wal`
  sibling is opened).
- The `zip` dependency is 9.8.1, which fixes the ZIP extraction advisories
  RUSTSEC-2026-0367, RUSTSEC-2026-0368, RUSTSEC-2026-0369 and
  RUSTSEC-2026-0429.
- `tauri-plugin-updater` is 2.14.1 and the Tauri stack is 2.12.7.
- `pnpm audit --audit-level high` reports no known vulnerabilities; the
  remaining `cargo audit` entries are informational advisories from Linux-only
  transitive crates, documented in `audit.toml`.
- ZCode credentials are decrypted in memory only and never appear in errors,
  logs or the UI. No new secret is stored outside provider-owned files.

## Other Changes

- JavaScript toolchain refreshed: Vite 8, Vitest 5, jsdom 31, Testing Library
  jest-dom 8, TypeScript 6, React 19.3, React Router 8.5 and the current Tauri
  CLI/API.
- New unit tests cover ZCode credential decryption, account-key mapping, team
  scoping, the 3.14+ settings format and `CREDIT_LIMIT` windows, plus Qoder
  `main.log` parsing and bundle-id log roots.
- The Qoder and ZCode provider setup guides describe the new sources and their
  limits.

See the [provider setup guide](../PROVIDER_QUOTA_SETUP.md) for source-specific
requirements and limitations.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v13.2.0 installer over the existing installation, or use the
   matching portable build.
3. Start lnwdeck and refresh providers once so the updated quota sources are
   collected.
