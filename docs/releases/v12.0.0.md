# lnwdeck v12.0.0

Release date: 2026-08-10

This release replaces every application icon with a refreshed, high-contrast
`LD` monogram pack so lnwdeck stays clearly visible on bright and dark
wallpapers, in the taskbar, Start Menu, Store listing and the installer.

## Changes

- **New LD monogram artwork.** All icons now use a dark rounded-square tile
  with a high-contrast `LD` monogram designed for Windows desktop visibility.
  Small app icons no longer carry a tiny wordmark, so the monogram stays
  legible at 16px.
- **Every surface updated.** The pack covers the taskbar sizes
  (16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 128x128@2x, 256x256),
  `icon.ico` / `icon.png`, `logo.ico` / `logo.png`, the Store tile set
  (Square30x30, Square107x107, Square142x142, Square150x150, StoreLogo) and
  the installer icon.
- **Pack documentation.** `apps/desktop/src-tauri/icons` now includes a
  README describing the design goal and the included files, plus a
  `PREVIEW.png` showing the pack at a glance.

## Privacy

- No prompts, responses, source code, file contents, file names, absolute
  paths or secrets are stored, and none are touched by this release.
- Credential, quota and usage behavior is unchanged from v11.0.9.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v12.0.0 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck.
