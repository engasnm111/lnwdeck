# lnwdeck v13.0.1

Release date: 2026-08-13

This release fixes update checks on machines where `github.com` is blocked or
degraded (the GitHub Asia node was returning empty replies, so the app could
not fetch `latest.json` and reported UPDATE_FAILED). Update checks now fall
back to CDN-hosted manifests and download installers through the GitHub API,
which is reachable where the release download page is not.

## Changes

- **CDN fallback endpoints.** The updater now tries three manifest endpoints
  in order: the GitHub release page, `raw.githubusercontent.com`, and jsDelivr.
  The release workflow commits `latest.json` to the repository root so the two
  fallback endpoints always serve the current manifest. If one endpoint is
  blocked, the next is tried automatically.
- **API-based downloads.** `latest.json` now references each installer by its
  GitHub API asset id (`api.github.com/.../releases/assets/<id>`) instead of
  the release download page URL. The API redirects to the same signed binary
  blob (`release-assets.githubusercontent.com`) and works in regions where
  `github.com` is unreachable.
- **Correct download headers.** The updater sends `Accept:
  application/octet-stream`, which the GitHub API requires to redirect to the
  binary instead of returning JSON metadata.
- **Signature verification unchanged.** Installers are still signed with the
  same key and verified against the embedded public key before installation;
  only the transport changed.

## Privacy

- No prompts, responses, source code, file contents, file names, absolute
  paths or secrets are stored, and none are touched by this release.
- Credential, quota and usage behavior is unchanged from v13.0.0; only the
  update-check transport changed.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v13.0.1 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and choose **Check for updates** from the tray to verify.

and build provenance after all architecture builds complete, and updates the
repository-root `latest.json` used by the CDN fallback endpoints.
