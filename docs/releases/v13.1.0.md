# lnwdeck v13.1.0

Release date: 2026-09-17

This release refreshes provider quota integrations against current provider and
TokenTracker-compatible sources, fixes stale/inactive provider handling, and
integrates the Windows titlebar into lnwdeck's own desktop shell.

## Features

- **Expanded provider quota coverage.** Added native quota adapters for Command
  Code, Devin, Ark Coding Plan, Ark Agent Plan, Qoder and Qoder CN.
- **Current provider-backed quota sources.** GitHub Copilot reads its published
  premium/chat quota, Gemini CLI uses its Cloud Code OAuth session, Grok
  prefers the Grok Build subscription pool, and OpenCode Go prefers its current
  usage API when an API key is explicitly configured while retaining the
  workspace-dashboard compatibility path.
- **Separated Google provider identities.** Antigravity is tracked separately
  from Gemini and uses the running IDE language server rather than sharing the
  Gemini CLI session.
- **Custom window chrome.** The main dashboard now uses frameless, app-drawn
  window chrome that blends with the existing lnwdeck theme. Dragging,
  minimize, maximize/restore, double-click maximize and the existing
  close-to-tray behavior remain available.

## Bug Fixes

- Removed providers are detected before collection, so stale local credentials
  no longer cause an uninstalled tool to be polled as if it were active.
- Ollama now detects its local API by reachability, so the absent-provider gate
  does not suppress its unlimited quota report while the local service is running.
- ZCode now honors the currently selected provider family before stale config
  entries.
- Codex handles the current spend-control credit bucket and Spark-specific
  rate-limit windows.
- Kiro CLI 2.13+ is reported as requiring a PTY instead of piping `/usage` as a
  model prompt and potentially spending credits.

## Other Changes

- The top bar uses the active page icon, clearer freshness state and a glass
  surface consistent with the rest of the desktop UI.
- Provider CLI calls are bounded by a timeout, reject unsafe Windows batch
  metacharacters and return only captured quota output.
- Gemini OAuth refresh reads public installed-app client metadata from the
  locally installed Gemini CLI bundle; no OAuth client secret is embedded in
  lnwdeck source code.
- New provider credentials stay in provider-owned files, process environment or
  the existing OS credential store and are not written to lnwdeck SQLite, UI
  read models or logs.

See the [provider setup guide](../PROVIDER_QUOTA_SETUP.md) for source-specific
requirements and limitations.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v13.1.0 installer over the existing installation, or use the
   matching portable build.
3. Start lnwdeck and refresh providers once so the latest quota sources are
   collected.
