# lnwdeck v0.8.0

## Z.AI quota, for real

- **ZCode** now reports the GLM Coding Plan quota: the published 5-hour,
  weekly and tool-call windows with real used percentages and reset times.
  Quota comes from the Z.AI / BigModel monitor API when a plaintext API key is
  stored in `~/.zcode/v2/config.json`, otherwise from the `billing/balance`
  records ZCode already wrote into `~/.zcode/v2/logs/`, with usage-only local
  windows as the final fallback.
- **Z.AI** estimates GLM usage from the Claude Code and OpenCode sessions the
  Coding Plan runs inside, and the pricing catalog covers the GLM model
  family.

## 12 new provider adapters

Every passive local source from the TokenTracker tool list:

| Provider | Source |
|---|---|
| ZCode | `~/.zcode/cli/db/db.sqlite` + Z.AI quota API |
| Z.AI (GLM) | GLM turns in Claude Code / OpenCode sessions |
| Kimi Code | `~/.kimi` / `~/.kimi-code` wire.jsonl |
| Kilo CLI | `~/.local/share/kilo/kilo.db` |
| Kilo Code | `ui_messages.json` task history |
| Mimo Code | `~/.local/share/mimocode/mimocode.db` (native turns only) |
| Roo Code | `ui_messages.json` + `api_conversation_history.json` |
| CodeBuddy | `~/.codebuddy/projects` |
| WorkBuddy | `~/.workbuddy/projects` |
| pi | `~/.pi/agent/sessions` |
| oh-my-pi | `~/.omp/agent/sessions` |
| Hermes | `~/.hermes/state.db` |

All adapters are read-only passive scans — nothing is installed into any tool,
no credentials are read, and only token counts, timestamps and model
identifiers ever leave the local files.

## Notes

- ZCode quota keys stored encrypted (`enc:v1:`) are not decrypted; the
  adapter falls back to the local balance logs, which carry the same numbers
  ZCode fetched.
- Z.AI publishes no server-side usage API for plain API keys, so the Z.AI
  adapter reports a local estimate with an unknown limit — the ZCode adapter
  shows the real plan quota for the same account.
- Hook-based integrations (Every Code, OpenClaw session plugin, omp notify
  extension) remain out of scope; the passive log readers cover the same
  tools.
