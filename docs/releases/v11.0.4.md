# lnwdeck v11.0.4

Release date: 2026-08-09

v11.0.4 is the clean-runner verification patch for the OpenCode Go quota
changes. It keeps the production behavior from v11.0.3 and aligns the
provider test contract with a machine that has no OpenCode Go credential.

## Changes

- OpenCode health tests accept `NotConfigured` when a local fixture database is
  present but the per-machine workspace credentials are absent.
- The regression suite continues to assert that missing credentials produce no
  unusable quota report and no dashboard request.
- Release procedure: push the versioned commit, wait for main-branch CI and
  Security to pass, then create and push the release tag. A release tag is not
  created while the main-branch gate is red.

The required OpenCode Go setup remains documented in
[`docs/PROVIDER_QUOTA_SETUP.md`](../PROVIDER_QUOTA_SETUP.md):
`OPENCODE_GO_WORKSPACE_ID` and `OPENCODE_GO_AUTH_COOKIE` must be configured on
each machine that should read the provider dashboard.

## Compatibility and privacy

- No database migration is required.
- Existing usage history and settings are unchanged.
- Credential values remain in the OS credential store or process environment;
  they never enter diagnostics, quota reports, logs or exports.
- Windows 10 22H2 and WebView2 remain supported requirements.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.4 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
4. On a machine without OpenCode Go, confirm its card shows the localized
   no-connection/not-configured state without a global refresh failure.

## Rollback

1. Use the last known-good v11.0.1 installer from the Releases page.
2. Install it over the current version.
3. Start the previous version and confirm history and settings remain readable.
