# lnwdeck v0.6.2

This release localizes the whole dashboard, makes every setting apply
immediately, and polishes the pet.

## Highlights

- **Full UI localization.** The dashboard now ships in nine languages
  (English, Thai, Chinese, Japanese, Korean, German, French, Spanish and
  Russian) with an instant language switcher in Settings. Every page —
  overview, providers, analytics, costs, budgets, models, alerts, system,
  pet and settings — is translated.
- **Locale-aware timestamps.** Dates use the selected language's calendar
  and a 24-hour clock with seconds (e.g. `07/08/2569 15:45:32` in Thai).
  The analytics event log shows readable `YYYY-MM-DD HH:mm:ss` local times.
- **Instant settings.** The Save button is gone: every control in Settings
  (refresh interval, retention, theme, startup, widget options, pet speed,
  stay-in-place, size, opacity, auto-sleep and pose toggles) writes through
  the backend the moment you change it, and the theme applies immediately.
- **Pet pose control.** Each ambient pose (wave, jump, look left/right,
  waiting, review) can be enabled or disabled from the Pet page or Settings,
  and the pet can be set to stay in place instead of walking.
- **Pet speech.** Clicking the pet shows a random quip built from live quota
  numbers (tokens used today, remaining quota, plan), held for a few seconds
  like TokenTracker's companion.
- **Smooth dragging.** The pet window now tracks the cursor in screen
  coordinates, which removes the jitter when picking the pet up.
- **Import guidance.** The codex-pets.net import field is wider and comes
  with a three-step guide in every language.
- **Tray check for updates.** Right-clicking the tray icon offers a manual
  "check for updates" that downloads and installs silently when a new
  version exists.
- **Polished alerts.** Alert cards get severity-colored accents and hover
  feedback, and alert/budget state badges are localized.

## Testing

  auto-save, alert severity, analytics filters).
- Cargo workspace tests, Clippy `-D warnings` and `cargo fmt --check` clean.
