# lnwdeck v11.0.9

Release date: 2026-08-10

This release adds detailed Gemini / Google / Antigravity quota windows read from
the running Antigravity IDE Language Server, keeps the desktop pet sprite
inside the screen when dragged or walking, and bundles the Prompt typeface so
every interface renders Latin and Thai glyphs consistently without depending on
fonts installed on the machine.

## Changes

- **Detailed Gemini quota from the Antigravity IDE.** When Antigravity IDE is
  running, lnwdeck discovers its Language Server process, reads the CSRF token
  from the server command line, and fetches the same per-model-group quota
  windows the IDE shows in Settings → Models: *Gemini Models* and *Claude and
  GPT models*, each with a *weekly* and a *5-hour* window, including remaining
  fraction and reset time. The request is local gRPC over HTTP/1.1 with HTTPS
  and the token never leaves the machine.
- **Fallback when the IDE is closed.** If Antigravity IDE is not running, quota
  still comes from the Gemini Code Assist `retrieveUserQuota` endpoint with the
  account's plan label (Free / Paid), so a closed IDE never produces a
  fabricated percentage.
- **Windows Credential Manager for Antigravity tokens.** The OAuth credential
  Antigravity stores in Windows Credential Manager (`gemini:antigravity`) is
  read directly when present, with the CLI `oauth_creds.json` file as fallback,
  and the refresh token is exchanged before use. No secret is written to
  SQLite, logs, UI or exports.
- **OAuth client read from the installed IDE.** The Google OAuth client the
  vendor ships with Antigravity is extracted at runtime from the installed
  IDE's `out/main.js` (the embedded `oauthClient.js` module), the same way
  TokenTracker reads gemini-cli's `oauth2.js`. No client identifier is
  hardcoded in source; when the IDE is not installed, refresh fails cleanly
  with a sanitized error instead of guessing a client.
- **No console window flash.** Language Server discovery spawns helper
  processes hidden (CREATE_NO_WINDOW), so refresh never pops a console window.
- **Desktop pet stays on screen.** The pet now clamps its visible sprite to the
  screen bounds instead of its larger transparent window box, so dragging or
  walking the pet keeps the sprite fully visible while the window may extend
  past the edge.
- **Bundled Prompt typeface.** The Prompt font (OFL-1.1) is vendored with the
  app in four weights (Regular, Medium, SemiBold, Bold) and used across the
  dashboard, widget, pet and tray. All surfaces render consistently offline,
  with system fallbacks when the font is not available.

## Privacy

- The Language Server quota request is loopback-only, uses the token the IDE
  itself already holds, and is never sent outside the machine.
- No credentials, cookies, prompts, responses or raw provider payloads are
  added to the UI, storage or logs.
- Existing quota history, account identity data and provider refresh behavior
  remain unchanged.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.9 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
