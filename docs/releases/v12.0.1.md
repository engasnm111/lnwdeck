# lnwdeck v12.0.1

Release date: 2026-08-11

This release makes the Antigravity IDE the only Gemini quota source and keeps
the last successful reading visible as old data, the way TokenTracker does:
closing the IDE never shows a fabricated percentage, and real numbers never
disappear.

## Changes

- **The Antigravity IDE is the only Gemini quota source.** Gemini quota is
  read exclusively from the running Antigravity IDE Language Server. The
  `retrieveUserQuota` fallback is removed: on real machines it returned
  placeholder fractions that surfaced as a fabricated "100% remaining" and
  overwrote accurate readings whenever the IDE was closed. No OAuth refresh
  or token exchange with Google is performed anymore.
- **TokenTracker-style caching.** When the Antigravity IDE is closed, the
  last successful reading stays visible as old data: the card flips from
  "Live" to "stale" the moment the IDE closes and shows exactly how long ago
  the data was fetched ("updated Xm ago"), in the floating widget, the pet
  tooltip, the Overview summary and the Providers cards. A closed IDE never
  shows a fresh percentage, and cached readings never vanish.
- **Guidance instead of silence.** Every surface tells the user what to do
  next — "Open Antigravity IDE to update Gemini quota" — instead of hiding
  the provider silently.
- **Account separation.** Gemini CLI and Antigravity IDE sessions are tracked
  separately: the account identity is derived from the credential that
  actually serves quota (Windows Credential Manager keyring first, the legacy
  `oauth_creds.json` fallback), so one account's data is never stored under
  another account's fingerprint.
- **Expected state, not an error.** `SOURCE_REQUIRES_IDE` never turns a
  refresh cycle into a global failure and never raises an alert.
- **Legacy data retired.** Placeholder reports stored by the removed fallback
  stop being displayed; nothing is deleted silently.
- **Freshness enforced at read time.** A stored reading older than its
  freshness window reads as stale everywhere, even before the next refresh.

## Privacy

- The Language Server quota request is loopback-only and never leaves the
  machine; the retired fallback no longer performs OAuth refresh-token
  exchanges or calls `cloudcode-pa.googleapis.com`.
- No credentials, cookies, prompts, responses or raw provider payloads are
  added to the UI, storage or logs.
- Quota history, account identity data and provider refresh behavior remain
  local and unchanged in shape.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v12.0.1 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
