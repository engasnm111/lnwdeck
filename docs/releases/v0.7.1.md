# lnwdeck v0.7.1

This is a focused reliability and usability patch release after v0.7.0.

## Fixed

- Budget entry fields use an aligned responsive grid; the toggle and save
  action are separated into a consistent action row.
- Manual Refresh All has a 60-second command bound and preserves the
  in-flight guard until the blocking worker exits, preventing an unresponsive
  UI and overlapping timed-out cycles.
- The sidebar alert badge reflects unacknowledged alerts and refreshes when an
  alert is acknowledged from the Alerts page.

## CI/CD

- Compile and UI E2E jobs use windows-latest, matching the runner that
  completed the v0.7.0 release matrix.
- Architecture checks compile the workspace without duplicating every test
  target; the dedicated test job still runs the full test coverage.

## Verification

- pnpm run test:ts
- pnpm run test:e2e
- pnpm run release:test
