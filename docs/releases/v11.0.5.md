# lnwdeck v11.0.5

Release date: 2026-08-10

This patch completes the quota display and account-isolation work requested
for the desktop widget and provider dashboard.

## Changes

- OpenCode Go accepts the current rolling 5-hour, weekly and monthly dashboard
  window names, including snake-case fields. A real monthly percentage is kept
  even when the provider omits its reset timestamp, so it no longer disappears
  or falls back to a fabricated 100% bar.
- Codex reset timestamps accept numeric seconds, numeric milliseconds and
  RFC3339 values, with the reset date rendered by the widget.
- Provider account identities are converted to installation-keyed fingerprints.
  Same-account App/CMD sources share a card; different fingerprints are stored
  separately without persisting the credential or account id. The read model,
  quota history and usage ingestion are account-aware.
- A Windows named mutex prevents duplicate lnwdeck processes from starting a
  second tray, widget or refresh loop.
- The pet quota tooltip is wider, uses less vertical spacing and displays full
  provider/window names with localized account labels.
- Providers that are absent on a machine remain localized as no connection;
  expected missing-provider refresh outcomes do not produce a global refresh
  failure message.

## Migration and privacy

- Migration `008_account_identity` preserves existing data in the default
  account bucket and allows multiple account fingerprints per provider.
- Raw tokens, cookies, API keys, account ids and filesystem paths remain out of
  SQLite, diagnostics, logs and the UI. Only keyed fingerprints cross the
  storage boundary.
- WSL environment variables remain isolated from the Windows process. The
  complete Windows-side setup and account-merging procedure is documented in
  [`docs/PROVIDER_QUOTA_SETUP.md`](../PROVIDER_QUOTA_SETUP.md).

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.5 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
4. Configure OpenCode Go on every Windows machine that should read its
   dashboard, using the documented workspace/cookie steps.
