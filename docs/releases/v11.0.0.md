# lnwdeck v11.0.0

Release date: 2026-08-09

v11.0.0 is the Costs Filter, Provider Identity and Tray Update Feedback
release. It keeps the existing local database and settings and adds the
following without storing prompts, responses, source code, file names,
absolute paths or secrets.

## Highlights

- **Costs page provider filter.** A dropdown above the cost table lists every
  provider with recorded events in the selected window. Choosing one narrows
  the rows and the priced total to that provider; the dropdown itself always
  stays complete, and the filter is fully translated in all nine locales.
- **Distinct OpenCode identities.** The billed Go implementation (`opencode`)
  is displayed as **OpenCode (Go)** and legacy free-CLI records
  (`opencode_cli`) as **OpenCode (Free)**. Costs, Analytics, Sessions, Models,
  Providers and the widget can no longer show two identical "OpenCode" rows
  with different data behind them.
- **Tray update feedback.** Choosing **Check for updates** from the native tray
  menu reports the result in the themed tray popup: an "up to date" banner
  with the running version when the check finds nothing newer, or a failure
  banner when the check cannot complete. The previous behavior only recorded a
  `UP_TO_DATE` event that no surface displayed.
- **Settings widget toggle works immediately.** "Show the floating quota
  widget" in Settings now shows/hides the native widget window through the
  same commands the tray uses, instead of only persisting a setting that took
  effect at the next restart.
- **Analytics time column left-aligned.** The timestamp column in the Usage
  Events table reads left-to-right like the date column on the dashboard
  instead of right-aligning like numeric cells.

## Compatibility

- The v11 database schema is unchanged from v10; existing databases open
  in place.
- Provider ids in stored events are unchanged; only the user-facing labels
  distinguish `opencode` from `opencode_cli`.

## Installing

1. Close lnwdeck (tray icon → Quit).
2. Install v11.0.0 over the existing installation or use the portable build.
3. Start lnwdeck and confirm the dashboard shows your existing history.

## Artifacts

| Architecture | Installer | Portable |
|---|---|---|
| x64 | `lnwdeck_11.0.0_x64-setup.exe` | `lnwdeck_11.0.0_x64_portable.zip` |
| ARM64 | `lnwdeck_11.0.0_arm64-setup.exe` | `lnwdeck_11.0.0_arm64_portable.zip` |
| x86 compatibility tier | `lnwdeck_11.0.0_x86-setup.exe` | `lnwdeck_11.0.0_x86_portable.zip` |

Each artifact ships with a `.sig`; the release also publishes `latest.json`,
`SHA256SUMS`, a CycloneDX SBOM and GitHub build provenance.

Minimum supported Windows version: Windows 10 22H2. WebView2 Runtime is
required and normally preinstalled.

## Localization

All new strings (costs provider filter, OpenCode labels, tray update banners)
are translated in English, Thai, Simplified Chinese, Japanese, Korean, German,
French, Spanish and Russian, with key and placeholder parity enforced by tests.

## Rollback

1. Download the previous release installer from the Releases page.
2. Install it over the current version.
3. Start the previous version and confirm history/settings are readable.
