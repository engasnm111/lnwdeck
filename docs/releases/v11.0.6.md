# lnwdeck v11.0.6

Release date: 2026-08-10

This patch fixes quota correctness and the provider dashboard viewport.

## Changes

- OpenCode Go recovers the monthly quota window from the current dashboard
  markup when the server-rendered payload omits it.
- Legacy default-account quota rows are hidden once an identified account is
  available, while genuinely different account fingerprints remain separate.
- The Providers page can scroll to the end of long provider-card grids. The
  application shell now allows its main grid item to shrink to the viewport so
  the existing content scrollbar owns the full page overflow.

## Privacy

- Historical quota rows remain intact; no user data is deleted.
- Raw credentials, cookies and account identifiers are not added to storage,
  logs or the UI.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.6 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
