# lnwdeck v0.5.0

This release adds a real desktop pet that walks across your screen, brings
fixed size presets to both the widget and the pet, fixes Codex usage
collection for the modern CLI format, and refreshes the whole application
with a new dark-first design language.

## Highlights

- **Desktop pet window.** A small transparent always-on-top window moves
  with the pet, so clicks pass through everywhere except the pet itself.
  The pet walks on its own (idle, left/right with an edge bounce,
  auto-sleep), and hover shows every quota window the providers published —
  real remaining percentages as colour-coded bars and usage-only windows as
  hatched "used" rows. Right-click opens a menu (Pet settings / Close pet),
  and left-press + drag picks the pet up anywhere on the monitor.
- **Six bundled default pets.** youyou, old-bai, a-ti, sharkler, solaire and
  tennis-ball from codex-pets.net ship inside the binary and install on
  first run with no network needed. Any community pet can be imported by URL
  or id; v1 and v2 spritesheets both render as animated atlases.
- **Pet page in the sidebar.** A dedicated page manages show/hide,
  character selection with live spritesheet previews, walk speed, size,
  opacity, auto-sleep and codex-pets.net imports.
- **Fixed size presets.** The widget window is now fixed-size — Small
  (300x300), Medium (400x420) or Large (500x500) — chosen in Settings and
  applied immediately; content scrolls inside and rings wrap to fit. The
  pet has its own presets (200x300 / 280x400 / 360x520) and the sprite
  scales with the window.
- **Settings gains widget layout.** Bars, Rings and Pet can be switched from
  the Settings page as well as from the widget header.
- **Codex usage collection fixed.** The Codex CLI now publishes usage in
  `event_msg/token_count` session records with cumulative totals and real
  rate-limit windows; the previous parser looked for a format that no longer
  exists. lnwdeck now takes each session's final cumulative total, reads the
  published limits as native quota (plan, weekly window, reset time), and
  walks the year/month/day session tree recursively.
- **Carbon & Emeralds design system.** Layered zinc neutrals on near-black
  carbon surfaces with a single emerald accent — no purple, no neon. Dark
  is the default; light mirrors it faithfully. Documented in
  [docs/DESIGN.md](DESIGN.md).
