# lnwdeck v11.0.1

Release date: 2026-08-09

v11.0.1 is a focused reliability and release-performance patch for the
v11.0.0 dashboard. It preserves the existing local database and settings while
fixing quota precedence, desktop pet rendering and auxiliary-window taskbar
behavior.

## Highlights

- **Correct Codex quota precedence.** The provider now asks the live usage API
  first. The newest local JSONL rate-limit snapshot is used only when the live
  provider is unavailable, while authentication-expired and rate-limited
  responses remain explicit errors. This prevents stale local snapshots from
  masking a real account or service condition.
- **Pet speech bubble stability.** The pet tooltip keeps its full hit surface,
  wraps long text and constrains its dimensions so the frame does not clip or
  become partially unclickable.
- **Auxiliary windows stay off the taskbar.** The pet, quota widget and tray
  popup are treated as overlays. Only a visible dashboard receives a Windows
  taskbar button, and restoring the dashboard re-enables its taskbar entry.
- **Faster release builds.** Cargo release settings keep parallel code
  generation and disable unnecessary LTO/incremental release artifacts. Windows
  links use `rust-lld`, CI uses target-specific Rust caching plus `sccache`, and
  the release job asks Tauri for only the shipped NSIS bundle.

## Compatibility and privacy

- The database schema is unchanged; existing history, settings and provider
  metadata remain in place.
- The release does not add cloud sync or store prompts, responses, source code,
  file contents, file names, absolute paths or secrets.
- Minimum supported Windows version remains Windows 10 22H2. WebView2 Runtime
  is required.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.1 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and confirm the dashboard, quota cards, pet and tray popup
   load as expected.

## Rollback

1. Download the v11.0.0 installer from the Releases page.
2. Install it over the current version.
3. Start the previous version and confirm history and settings remain readable.
