# lnwdeck v11.0.8

Release date: 2026-08-10

This patch aligns the pet quota tooltip so provider labels, quota tracks and
percentages form predictable columns even when provider names have different
lengths.

## Changes

- Provider names are left-aligned in one shared tooltip column.
- Quota tracks start on one shared right-side column instead of shifting with
  the width of each provider label.
- Percentage values finish on one shared right edge across every quota row.
- Existing spacing, glass frame bounds, scrolling and tooltip content remain
  unchanged.
- Added a regression test covering the shared grid structure and label
  alignment.

## Privacy

- No credentials, cookies, prompts, responses or raw provider payloads are
  added to the widget or pet UI.
- Existing quota history and account identity data remain unchanged.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.8 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
