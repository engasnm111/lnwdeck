# lnwdeck v0.9.0

## Sessions — token usage per project folder

A new **Sessions** page tracks usage per session and per project folder, the
same view TokenTracker popularizes: each folder groups its sessions, each
session has a name, and every row shows requests, input/output tokens, cost
and last-used time.

- **Grouped by folder.** Events are attributed to a project (folder) and a
  session through keyed hashes (HMAC-SHA-256 with the machine-local secret).
  Raw folder paths and session ids are never stored — attribution is
  privacy-safe by design.
- **Named sessions.** Default labels (`Project 01`, `Session 01`) are
  replaced by user-entered names stored as metadata only; rename inline and
  the page remembers it.
- **Unassigned bucket.** Records from providers that do not expose a session
  identifier (Copilot, Claude, Cursor, …) appear under *Unassigned* until
  their adapters learn to report sessions; OpenCode already attributes every
  event to its session and folder hashes.
- Window tabs (24h / 7d / 30d / all) and a provider filter, matching the
  Models page. Thai and English strings for every control.

## Costs now show prices

The Costs page showed "no catalog entry" for almost every real model because
the bundled price catalog covered only 37 models with exact-name matching.

- **Real catalog.** The bundled offline snapshot now covers **1,389 models
  across 11 providers**, generated from the LiteLLM price file (MIT) by
  `scripts/update-pricing-catalog.mjs`.
- **Tolerant matching.** Provider aliases (`anthropic_claude` → Anthropic,
  `google_gemini` → Google, …), vendor-prefixed ids (`anthropic/claude-sonnet-4`)
  and dated variants (`claude-sonnet-4-20250514`) all resolve; opencode-go
  events are priced with their own family's rates (GLM, Claude, GPT, …).
- **Everything has a cost.** A model that still matches nothing is charged a
  labeled generic estimate (clearly marked *estimated*), never a blank cell —
  and never with an unrelated provider's rate.

## Also fixed

- **Dark-mode dropdowns.** The native select popup rendered white in dark
  theme, making the text invisible; the control now pins its color scheme and
  paints option rows with opaque theme colors.
- **Two new bundled default pets** from codex-pets.net — *Friend Pixel Pet*
  and *Yae Miko* — join the six bundled pets, installed offline on first run.
