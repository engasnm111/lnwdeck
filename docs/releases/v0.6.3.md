# lnwdeck v0.6.3

This release fixes the refresh freeze, makes every corner of the app
localizable, and ships the browser helper with the installer.

## Highlights

- **Refresh never freezes the UI.** Collection runs on a dedicated worker
  with its own SQLite connection, so the dashboard stays responsive while
  providers are scanned. Overlapping cycles are rejected, a hard 5-minute
  timeout guarantees the command always answers, and the refresh button
  shows a spinner while a cycle runs.
- **Complete localization (9 languages).** Every page, the floating widget,
  the pet (tooltip + random quips + context menu), the tray menu and the
  update banner are translated: English, Thai, Chinese, Japanese, Korean,
  German, French, Spanish and Russian.
- **Tray: Sync now + Show/Hide Pet.** Right-click the tray icon for
  "Sync now (HH:mm)" (last successful sync time) and a pet visibility toggle
  that stays in sync however the pet is closed.
- **Diagnostics export.** The System page writes a sanitized JSON snapshot to
  the user's Downloads folder and can open the folder with the file selected.
- **Browser helper ships with the installer.** The native messaging host is
  built and bundled, the registration script is fixed, and quota detections
  from the extension are recorded into the app's event log.
- **Playwright UI smoke tests.** A new E2E suite drives the real WebView2
  frontend (via CDP) against the real backend: boot, navigation and
  language switching — wired into CI.
- **Pet click-through.** The pet window only intercepts clicks over the
  sprite/tooltip; the rest passes through to the desktop underneath.
- **Locale-aware timestamps.** 24-hour day/month/year times follow the UI
  language (e.g. `07/08/2569 15:45:32` in Thai), and the analytics event log
  shows readable `YYYY-MM-DD HH:mm:ss` local times.

## Testing

- Vitest: 170 tests green.
- Cargo workspace tests, Clippy `-D warnings` and `cargo fmt --check` clean.
- Playwright UI E2E (3 specs) green against a release build.
- Release build verified locally on x64 before tagging.
