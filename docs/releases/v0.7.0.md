# lnwdeck v0.7.0

This release is a full visual redesign: every window now speaks the Premium
Dark Futuristic Glassmorphism design language, from the dashboard shell to the
floating widget and the tray popup.

## Highlights

- **New design system — Premium Dark Futuristic Glassmorphism.** The whole
  application is rebuilt on a new design language: a near-black navy canvas
  (`#05070F`) lit by ambient cyan, blue and violet glows, frosted glass panels
  (translucent white fills, soft blur, thin glowing borders, layered
  elevation), and a cyan → violet accent family. The amber → red warm
  gradient is reserved for primary call-to-action buttons, so attention lands
  where it belongs. `docs/DESIGN.md` documents the full language.
- **Atmospheric background.** Fixed gradient orbs drift gently behind the
  dashboard, a faint grid fades toward the edges, and a low-opacity SVG noise
  grain adds depth — all motion on transform/opacity only, all disabled under
  `prefers-reduced-motion`.
- **Glass shell.** The sidebar and topbar are frosted navy glass; the active
  navigation item carries a cyan → violet wash with a glowing indicator, and
  page titles shimmer with a slow cyan → violet gradient on hover.
- **Premium interactions.** Cards and metric tiles lift with a subtle glow on
  hover, primary buttons run a shine sweep across the amber → red face,
  progress bars and toggles use the cyan → blue gradient, and the page-title
  shimmer respects reduced motion.
- **Floating widget matches the new language.** The widget card is now a
  frosted navy glass panel with a glowing border and the same cyan → violet
  top-edge accent as the dashboard, so it reads as part of the same product.
- **Tray popup restyled.** The tray card, brand mark and metrics follow the
  new cyan/blue/violet palette with a glass surface.
- **CI/CD hardened.** The Windows build pipeline no longer dies silently
  mid-compile on the hosted runner: real-time Defender scanning is excluded
  from the build directories, the pagefile is enlarged, cargo steps retry
  transient kills and print memory/disk diagnostics on failure, and the
  ARM64 compile job gets the LLVM toolchain it needs. The release pipeline now
  also publishes a portable ZIP per architecture instead of overwriting all
  three with one file.
