# lnwdeck v0.4.0

This release adds the animated pet layout to the floating quota widget. The
pet is decorative and reacts to the same real quota dashboard data the bars
and rings layouts already show — no percentage is estimated, and providers
that publish no limit stay explicitly unavailable.

## Highlights

- **Pet layout.** A third widget layout, chosen from a picker in the header,
  renders the quota rows from bars mode below a small self-authored robot pet.
  The pet's mood is derived from the visible providers only, after the
  provider filter is applied: happy when a real remaining percentage is above
  50, worried at 20-50, critical below 20, puzzled when a reading is stale,
  sad on auth, rate-limit or collection errors, and sleeping when no visible
  provider published a usable percentage. A successful manual refresh plays a
  short celebration and returns to the derived mood.
- **Three-way layout picker.** Bars, Rings and Pet are selected explicitly;
  the two-state toggle is gone and an invalid stored layout still falls back
  to bars.
- **Only fetched quota is shown.** Providers whose quota collection failed
  (not configured, not authenticated, rate limited, or a collector error) are
  hidden from the widget until they recover; open the dashboard for the
  reason. Stale readings stay visible and are labelled, and the widget states
  an explicit message when every provider failed.
- **Accessible and polite animation.** All animation is CSS transform and
  opacity (no JavaScript animation loops) and stops under
  `prefers-reduced-motion`. The pet SVG is hidden from assistive technology;
  the mood is announced as text and the quota rows keep their full
  progressbar semantics.
- **Drag behavior preserved.** While unlocked, the pet stage also drags the
  window like the header; Lock removes every drag region and the controls stay
  interactive.

## Notes and limitations

- The pet stays inside the widget; free roaming across the desktop is not part
  of this release.
- The pet has no click interactions or sounds.
- All artwork is inline SVG in the repository; no emoji, no remote assets and
  no third-party characters.
