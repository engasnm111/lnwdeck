# lnwdeck v11.0.7

Release date: 2026-08-10

This patch makes the desktop pet compact and keeps the floating widget honest
about which provider quotas were actually fetched.

## Changes

- Pet quota rows use content-sized labels and tracks with a maximum 20px visual
  gap, so the center of the glass tooltip no longer contains a large empty
  region.
- The quota frame remains bounded by the viewport and keeps its border,
  rounded corners, scrolling and arrow intact.
- Short pet speech bubbles fit their message; longer messages wrap within a
  safe viewport-constrained width.
- The floating widget hides providers that were not fetched successfully,
  including providers that remain selected from an earlier configuration.
- The provider picker continues to list configured providers so a failed source
  can be selected again after its credentials or local installation is fixed.

## Privacy

- No credentials, cookies, prompts, responses or raw provider payloads are
  added to the widget or pet UI.
- Existing quota history and account identity data remain unchanged.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.7 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
