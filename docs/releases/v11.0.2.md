# lnwdeck v11.0.2

Release date: 2026-08-09

v11.0.2 is the provider quota truth and pet readability patch. It preserves
the existing local database and settings while making the quota surface honest
when a provider is absent, unsupported or not configured on the current
machine.

## Highlights

- **No fabricated quota.** Provider bars and rings now come from authoritative
  provider limits. A provider that is not installed or detected is shown as
  `No connection`; a provider with usage but no supported limit remains
  usage-only. Neither state is converted into 0%, 100% or a locally invented
  rolling-window percentage.
- **Partial refresh is quiet.** Missing providers do not make the combined
  refresh report a failure. A real authentication, network or schema error is
  still retained on the affected provider so it can be diagnosed independently.
- **OpenCode (Go) is per-machine.** Each machine must provide both
  `OPENCODE_GO_WORKSPACE_ID` and `OPENCODE_GO_AUTH_COOKIE`, or enter the pair
  in Settings. The cookie may be pasted as its raw value or as `auth=...`.
  Quota is read from the authenticated workspace dashboard; local token totals
  are never used as an automatic substitute. See
  [`docs/PROVIDER_QUOTA_SETUP.md`](../PROVIDER_QUOTA_SETUP.md) for the complete
  PowerShell procedure and security warnings.
- **Corrected provider sources.** Claude, Codex, Gemini, Cursor, ZCode and Kimi
  now use their corrected quota paths. Kimi reads the TokenTracker-compatible
  `usage`/`limits` response from `https://api.kimi.com/coding/v1/usages` and
  refreshes an expired OAuth access token in memory without rewriting the
  provider-owned credential file.
- **Readable pet quota labels.** Pet rows keep the provider and window as
  separate visible labels, so `OpenCode (Go) — 5-hour`, `7-day` and `30-day`
  remain distinguishable. The medium pet window is wider to leave room for
  the complete label and percentage.

## Compatibility and privacy

- The SQLite schema is unchanged; existing history, settings and provider
  metadata remain in place.
- OpenCode Go credentials are read only from the explicit Settings or
  environment setup path. They are not written to SQLite, UI read models,
  logs, exports or release artifacts.
- Kimi's refreshed access token is held only for the current refresh operation;
  lnwdeck does not modify Kimi's credential file.
- Minimum supported Windows version remains Windows 10 22H2. WebView2 Runtime
  is required.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.2 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and confirm the dashboard, quota widget and pet tooltip load.
4. On a machine that has OpenCode Go, configure the two values described in
   [`docs/PROVIDER_QUOTA_SETUP.md`](../PROVIDER_QUOTA_SETUP.md) before refreshing.

## Rollback

1. Download the v11.0.1 installer from the Releases page.
2. Install it over the current version.
3. Start the previous version and confirm history and settings remain readable.
