# lnwdeck v11.0.3

Release date: 2026-08-09

v11.0.3 is a correctness patch for the v11.0.2 provider-quota release. It
keeps the quota display honest on clean machines where OpenCode is not
installed and no OpenCode Go workspace credentials have been entered.

## Changes

- OpenCode (Go) preserves the `NOT_CONFIGURED` detection state when both its
  local SQLite source and per-machine credentials are absent.
- The OpenCode Go quota adapter returns a sanitized `NOT_CONFIGURED` collection
  error without creating an unusable quota report. This prevents the runtime
  contract from treating a failed report as a successful result.
- OpenCode health now reports `NotConfigured` for the missing-credential state.
- Regression tests cover clean-machine detection and the provider quota
  contract, including the no-network path for missing credentials.

The full OpenCode Go setup procedure, including the required
`OPENCODE_GO_WORKSPACE_ID` and `OPENCODE_GO_AUTH_COOKIE` values, remains in
[`docs/PROVIDER_QUOTA_SETUP.md`](../PROVIDER_QUOTA_SETUP.md).

## Compatibility and privacy

- No database migration is required.
- Existing OpenCode usage history is unchanged.
- Credential values remain in the OS credential store or process environment;
  they are never written to quota reports, diagnostics, logs or exports.
- Windows 10 22H2 and WebView2 remain the minimum supported desktop runtime.

## Installing

1. Close lnwdeck from the tray menu.
2. Install the v11.0.3 installer over the existing installation, or use the
   portable build.
3. Start lnwdeck and refresh providers.
4. On a machine without OpenCode Go, confirm its card says no connection or
   not configured and that the combined refresh remains usable.

1. Download the v11.0.2 installer from the Releases page.
2. Install it over the current version.
3. Start the previous version and confirm history and settings remain readable.
