# lnwdeck v0.6.0

This release fixes Gemini quota and usage collection for Antigravity users,
resizes the pet window at runtime, keeps windows alive for tray reopening,
and restricts pet dragging to the pet itself.

## Highlights

- **Gemini quota windows from the Code Assist API.** lnwdeck now reads the
  OAuth token the Gemini CLI / Antigravity stored in `~/.gemini/oauth_creds.json`
  and fetches real per-model request windows (Gemini Pro / Flash / Flash-Lite)
  with remaining percentage and reset time from Google's Code Assist API. When
  no token is present or the API is unreachable, the local usage estimate is
  used instead.
- **Antigravity usage collection.** Session transcripts from
  `~/.gemini/{antigravity,antigravity-ide,antigravity-cli}/brain/**/logs/` are
  now scanned together with Gemini CLI chats. Usage is estimated from content
  the same way the reference implementations do (one token per CJK character,
  one per four others), with context deltas billed as input and planner
  responses as output, and the selected model is picked up from the transcript.
- **Pet size applies immediately.** The settings payload used snake_case field
  names while the backend serializes camelCase, so the pet window never
  resized from the Pet page. The names now match and the sprite scales with
  the window.
- **Tray reopen after close.** Closing the main window destroyed it instead of
  hiding it, so the tray icon had nothing to reopen; `CloseRequested` now
  prevents the close and hides to the tray for all three windows.
- **Drag only on the pet.** Pointer handlers moved from the window surface to
  the pet sprite, so transparent window areas no longer grab the pet.
