# inwdeck v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use an inline task-by-task execution workflow unless the user explicitly authorizes subagents. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows-first, local-only Universal AI Usage Tracker with ten provider groups, full analytics, Browser Helper, Tray, Floating Widget, sandboxed community adapters and signed updates.

**Architecture:** Use a Rust modular core behind Tauri commands, React read-model UI, SQLite persistence, built-in provider crates and Wasm-isolated community adapters. All collected data passes a normalized contract and central Privacy guard before persistence.

**Tech Stack:** Tauri, Rust, React, TypeScript, Vite, pnpm, SQLite, serde, schemars, async Rust, Vitest, React Testing Library, Playwright, Chromium Manifest V3, Native Messaging, GitHub Actions.

## Global Constraints

- Product name is `inwdeck`.
- Windows support is Windows 10 22H2 and Windows 11.
- x64 and ARM64 are Tier 1; x86 is Compatibility Tier.
- v0.1 is local-only and has no inwdeck account or cloud sync.
- Persistent data is Metadata-only.
- Prompt, response, source code, file name, absolute path, Cookie and credential data must never be persisted.
- Hooks start in Passive mode and require per-provider user approval.
- Browser Helper supports Edge and Chrome through Manifest V3.
- Installer is per-user; Portable ZIP is also shipped.
- Updates download in the background and require explicit Restart.
- Do not spawn subagents unless the user explicitly authorizes them.
- Work on one Task at a time and stop for review after its commit.

## Plan self-review

- Every locked product decision maps to at least one Task
- Provider implementation is split into separate review gates
- Privacy boundary exists before any real Provider adapter
- Browser, Hook, API, local logs and local API collection modes are covered
- Analytics and pricing are implemented before UI completion
- Architecture matrix and updater are covered
- No Cloud functionality is included
- No Task authorizes Prompt/Response persistence
